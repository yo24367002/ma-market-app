# 全球市场参谋 📈

每日自动更新的全球市场分析 App（PWA，iPhone/手机浏览器打开即可使用）。

## 功能
- **全球指数**：美/日/港/韩/澳/新加坡/英/德 10 大指数实时行情
- **ETF / 个股**：10 个全球 ETF + 9 只代表性美股，含估值（PE/PB/股息率）
- **风险评分**：波动率 35% + 趋势 25% + RSI 极端度 20% + 52 周位置 20%，输出 0-100 分与风险等级
- **AI 解读**：Gemini 每天生成「今日市场环境 / 今日值得关注 / 平衡型投资者提示」
- **SBI 持仓诊断**：粘贴 SBI 持仓 CSV，自动估算市值、盈亏并对照每日数据池

## 数据更新
GitHub Actions 每天日本时间 08:00 自动拉取 Yahoo Finance 行情 → 计算指标 → 调用 Gemini 生成解读 → 更新 `web/data.json`。

## 使用
1. 手机 Safari 打开：`https://yo24367002.github.io/ma-market-app/`
2. 分享 → 添加到主屏幕（Add to Home Screen）→ 桌面出现 App 图标
3. 数据每日自动更新，打开即看
